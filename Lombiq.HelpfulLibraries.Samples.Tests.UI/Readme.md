# Lombiq Helpful Libraries for Orchard Core - Samples - UI Test Extensions

UI tests verifying Lombiq Helpful Libraries Samples behavior, and thus testing some Lombiq Helpful Libraries features at a high level.

Since the project depends on `Lombiq.HelpfulLibraries.Samples`, for it to be published to NuGet, the Samples project would also need to be published, what doesn't make much sense. So, this project isn't published to NuGet.
